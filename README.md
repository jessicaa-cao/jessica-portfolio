# Jessica Cao - Portfolio

Clean, minimal portfolio with interactive home page and separate content pages.

## Quick Start

```bash
cd jessica-portfolio
npm install
npm start
```

## Deploy to Vercel

```bash
vercel
```

## Design Features

- **Interactive cursor blob** on home page
- Clean blue & cream color scheme
- Separate pages for About, Work, and Beyond
- Minimal, human-designed aesthetic
- Smooth page transitions
- Fully responsive

## Customizing

All content is in the component files:
- `src/components/About.js` - About page content
- `src/components/Work.js` - Projects and experience
- `src/components/Beyond.js` - Hobbies and interests

Colors can be adjusted in `src/App.css` under `:root` variables.
